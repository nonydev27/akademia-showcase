# Akademia Showcase

Landing page for [Akademia](https://github.com/nonydev27/akademia-showcase) — a modern school management platform built for Ghanaian Primary, JHS, and SHS schools.

## What's here

A single-file static showcase site (`index.html`) with:
- Hero section with live app dashboard preview
- Full feature breakdown (12 features)
- How It Works walkthrough
- Role-based access explainer (Super Admin, School Admin, Staff)
- Result-Fee Intercept deep-dive
- "See It In Action" — 6 screen previews
- FAQ (10 questions)
- Microsoft Store & App Store badges
- Footer

## Tech

Pure HTML + CSS + vanilla JS. No build step. No dependencies. Deploy anywhere.

## Deploy

Just serve `index.html` from any static host — GitHub Pages, Netlify, Vercel, etc.
